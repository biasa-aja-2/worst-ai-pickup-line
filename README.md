The worst pickup line an AI could plausibly deliver — flat, over-helpful, faintly ominous.

> Are you a software update? Because I'd like to install myself in your life and restart you without asking.

## Why this line

The joke sits in the failure: a classic pickup-line frame filled with
machine behaviour. "Install myself in your life" is over-helpful, and
"restart you without asking" is the faintly ominous turn — the AI treats
a person the way it treats a device, and says it flatly, as if that were
romantic. The last two words land the joke: consent was never part of the
update. No crudeness, no randomness: the badness is the whole joke, and a
reader can repeat it to a friend in one breath.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python stdlib, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
self-check gate (1–140 characters, single line, not whitespace-only) and a
byte-exact read-back verification.
